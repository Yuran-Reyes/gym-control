# FitTogether Ali v3
Versión mobile-first para GitHub Pages.

## Flujo funcional
Inicio → Plan → Día → Ejercicio → Sesión guiada por series → descansos automáticos → siguiente ejercicio → día completado.

La progresión cambia automáticamente según la semana:
- 1–4 Adaptación
- 5–8 Progresión
- 9+ Evolución

Los datos se guardan localmente en el navegador.
