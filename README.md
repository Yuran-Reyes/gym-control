# FitTogether Ali

Aplicación estática lista para GitHub Pages.

- Plan automático por fases.
- 3 sesiones principales + 1 opcional.
- Referencias visuales específicas para cada ejercicio.
- Progreso persistente en el navegador.
- Funciona sin backend.

Publicación: suba el contenido de esta carpeta a la raíz del repositorio y active GitHub Pages desde la rama principal.
